## 🚀 Getting Started

Follow these steps to download and open ApexWare on Windows.

1. Open the ApexWare download page:

   [Download ApexWare from GitHub](https://github.com/Tripop123/apexware-software-hub)

2. On the GitHub page, find the green **Code** button near the top of the file list.

3. Select **Code**, then choose **Download ZIP**.

4. Windows will save a compressed ZIP file in your **Downloads** folder. The file name will use the project name, such as `apexware-software-hub-main.zip`.

5. Open the **Downloads** folder.

9. Open the extracted `apexware-software-hub` folder.

10. Find the main HTML file. It is often named `index.html`.

11. Double-click `index.html`. Windows should open the page in your default browser.

Do not open the HTML file from inside the ZIP file. Extract the full folder first so the page can load its related files.

## 🛠️ Fix Common Problems

### The page does not open

Right-click the main HTML file, select **Open with**, and choose Microsoft Edge or another supported browser.

### The page looks empty

Make sure you extracted the whole ZIP file. The HTML page may need its CSS, JavaScript, image, or data files in the same folder structure.

### The page has no styling

Do not move the HTML file away from the other project files. Keep the folder structure created by **Extract All**.

### A link does not work

Some links need an internet connection. Check that Windows is online, then refresh the page with `Ctrl + R`.

### Windows blocks the file

Right-click the extracted file, select **Properties**, and check for an **Unblock** option near the bottom of the window. If that option appears, select it, choose **Apply**, and open the file again.

### The ZIP file will not extract

Download the ZIP file again from the project page. A partial download can stop Windows from extracting the folder.

### The browser shows the source text

You may have opened a file in a text editor. Close it, right-click the HTML file, select **Open with**, and choose a web browser.
